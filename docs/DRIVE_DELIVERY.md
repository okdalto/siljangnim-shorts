# 최종본 Google Drive 전달

영상 한 편마다 사용자가 승인한 최종 버전의 아래 세 파일을 업로드한다.

| 파일명 | 내용 |
|---|---|
| `<주제>_final.mp4` | 한영 자막이 포함된 1080×1920·60fps 최종 영상 |
| `<주제>_thumbnail.png` | 최종 썸네일 |
| `<주제>_caption_KO_EN.txt` | 한국어와 영어 게시글을 합친 UTF-8 텍스트 파일 |

게시글 TXT는 한국어 본문 → 영어 본문 → 중복 없는 공통 해시태그 최대 5개 순서로 작성한다. 전체 내용을 한 번에 복사해 게시할 수 있도록 본문을 연속해서 배치한다.

## 업로드 위치와 확인

1. 기존 `쇼츠들` 폴더 안의 `YYYY-MM-DD 주제` 하위 폴더를 확인·재사용한다.
2. 위 세 파일의 이름과 최종 버전을 확인하고 업로드한다. 기존 성공 기록이 있으면 해당 파일을 확인·재사용한다.
3. 업로드한 파일의 이름·부모 폴더·크기를 메타데이터로 확인한다.
4. 로컬 전달 기록에 파일별 ID·URL·SHA-256과 검증 결과를 저장한다.
5. 사용자에게 확인된 폴더 링크를 전달한다.
