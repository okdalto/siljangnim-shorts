uv run --locked python -m unittest discover -s tests -v

테스트는 현재 스킬의 상태·수정 충돌·캐시·발화 정렬·SRT·읽기 전용 뷰어를 확인한다. 외부 유료 음성 생성은 자동 테스트에서 호출하지 않는다. 영상의 시각 품질과 발음·연기는 실제 결과를 보고 들은 별도 검수 기록으로 판단한다.

## v1.0.0 코드 정리 검증 (2026-10-16)

- 격리된 기본 의존성 환경에서 테스트 15개 통과, 렌더러 JavaScript 구문 검사 통과.
- 기존 프로젝트의 6개 장면에서 실제 George 음성과 발화 정렬 캐시 재사용 확인. 유료 음성 생성 호출은 차단한 상태로 검증했다.
- 기존 프로젝트 복사본을 40.67초·1080×1920·60fps로 렌더링했다. 오디오 트랙, 길이, 최종 영상·미리보기 전체 디코딩, 썸네일·한영 SRT 생성을 확인했다.
- Manim의 원→사각형 변형을 1080×1920·60fps로 별도 렌더링했다.
- 생성된 대표 프레임을 확인했다. 이번 검증은 제작 경로 회귀 검사이며 새 발음·연기 검수가 아니다.
- 릴리스의 승인된 37.7초 홍보 영상과 썸네일은 기존 최종본과 SHA-256이 동일하다. 검증용 프로젝트 렌더로 교체하지 않았다.
